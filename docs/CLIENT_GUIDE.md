## 1. まず知っておいてほしいこと

- **スマホで見る前提**で作っています。まずスマホで開いてください。パソコンでも崩れません。
- ここに入っている商品・利用者は、**動きを確かめるための架空のデータ**です。
  自由に買ったり売ったりして構いません。
- **お金は動きません。** クレジットカードの入力も不要です(下の「3. いまは本物ではないもの」)。

## 2. 試してほしいこと

上から順に触ると、ひととおりの流れを確認できます。所要 15 分ほど。

### さがす・買う

- [ ] トップページから、気になるカテゴリ(ロードバイクなど)を開く
- [ ] 検索窓に「トレック」「ぴなれろ」など**カタカナやひらがなで**メーカー名を入れる
      → 英語表記の商品が出てくるか
- [ ] 絞り込み(価格・サイズ・地域・メーカー)で、欲しい条件に近づけられるか
- [ ] 商品ページの情報に、**買うかどうかを決めるのに足りない項目がないか**
- [ ] ハートを押してお気に入りに入れ、あとから一覧で見返せるか
- [ ] 出品者に質問を送り、相手の画面に届くか(別のアカウントでログインして確認)
- [ ] 購入してみる(お金は動きません)

### 売る

- [ ] 「出品する」から、写真を選んで商品を登録する
- [ ] メーカーの選択欄で、**扱いたいメーカーがすべて入っているか**
      (無ければ「その他」で自由入力できます。足りないメーカーは教えてください)
- [ ] 価格を入れたとき、手数料を引いた**受取額の表示**が期待どおりか
- [ ] 途中でやめて下書き保存し、あとから続きを書けるか

### 買ったあと

- [ ] 取引画面で、次に何をすればよいかが分かるか
- [ ] 売る側で「発送しました」、買う側で「受け取りました」を押す
- [ ] お互いを評価すると取引が完了し、商品が SOLD になるか

### 管理画面(運営として使う画面)

- [ ] `/admin` を開く(管理者アカウントでログインしてから)
- [ ] 通報された商品を見つけて、非表示にできるか
- [ ] メーカーの追加・名前の変更・無効化ができるか
- [ ] 日々見たい数字(会員数・出品数・取引数・売上)が足りているか

## 3. いまは本物ではないもの

検証の段階なので、次の4つは**わざと本物につないでいません**。
見た目と流れは本番と同じです。

| もの | いまの状態 | 本番でどうなるか |
|---|---|---|
| クレジットカード決済 | カード入力の代わりに確認画面が出て、押すと支払い済みとして進む | Stripe の決済画面が出る。取引が進む仕組みは今と同じ |
| メール通知 | 送信せず記録だけ残す | 購入・発送・受取・評価などの通知が実際に届く |
| Google でログイン | ボタンは出るが認証は通らない | Google のアカウントでログインできる |
| 利用規約・プライバシーポリシー・特定商取引法に基づく表記 | 「準備中」と表示 | いただいた文面と事業者情報を載せる |

**4つ目だけは、こちらで文面を用意できません。**
事業者名・所在地・連絡先・返品の条件などをご用意ください(様式はこちらで用意済みです)。

## 4. 気づいたことの伝え方

次の4点があると、こちらで再現して直せます。スクリーンショットがあれば最良です。

1. **どの画面で**(例: 商品ページ / 出品フォーム)
2. **何をしたか**(例: 価格に 100000 と入れた)
3. **どうなってほしかったか**
4. **実際どうなったか**

> 「ここが使いにくい」「この言葉が分かりにくい」も歓迎です。
> 直せるものと、仕様上そうしているものを分けてお返しします。

---

## 5. 画面に出てくる言葉

| 言葉 | 意味 |
|---|---|
| 下書き | 出品を途中まで書いて保存した状態。まだ誰にも見えない |
| 公開中 | 売り出し中。誰でも買える |
| 取引中 | 誰かが購入し、発送や受け取りが進んでいる最中 |
| SOLD(売却済) | 取引が終わった商品 |
| 取下げ | 出品者が自分で売るのをやめた状態。後から再公開できる |
| 非公開 | 運営が見えないようにした状態。出品者は自分では戻せない |
| メーカー | 自転車のブランド(Trek、ジャイアントなど)。約190社から選べます |

## 6. よくある質問

**Q. 触って壊しませんか?**
A. 壊れません。検証用のデータなので、消しても登録し直せます。

**Q. 本物のクレジットカードを入れてしまいそうで怖い**
A. いまの検証環境には**カードの入力画面そのものがありません**。

**Q. 自分のスマホの連絡先やカメラを使いますか?**
A. 写真を選ぶときだけカメラロールを使います。ほかは使いません。

**Q. 公開はいつできますか?**
A. 決済(Stripe)の審査と、規約類の文面が揃えば公開できる状態です。

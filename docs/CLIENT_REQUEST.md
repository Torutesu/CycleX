## C. 運用アカウント(🔴 / 名義は甲)

サービスの継続運営に関わるため、**すべて甲名義で作成**していただくのが原則です
(乙名義だと契約終了時に引き継げません)。作成手順はこちらでご案内できます。

| #   | サービス         | いただくもの                                                 | 備考                                                               |
| --- | ---------------- | ------------------------------------------------------------ | ------------------------------------------------------------------ |
| C-1 | **Supabase**     | プロジェクト(Tokyo リージョン)への招待、または API キー 3 種 | DB・認証・画像保管。無料枠で開始可                                 |
| C-2 | **Vercel**       | プロジェクトへの招待                                         | アプリの実行環境。無料枠で開始可                                   |
| C-3 | **Resend**       | API キー + 送信元アドレス(`EMAIL_FROM`)                      | 🔴 メール送信。無料枠あり(通数は申込時にご確認ください)            |
| C-4 | **Google Cloud** | OAuth クライアント ID / シークレット                         | 🔴 Google ログイン(FR-01-2)。**要件に含まれます**                  |
| C-5 | **Sentry**       | DSN(1 行の URL)                                              | 🟡 障害の通知。無料枠は月 5,000 件。無いと障害がログにしか残らない |

`EMAIL_FROM` は `CycleX <noreply@(B-2 のドメイン)>` の形式でお願いします。
このアドレス宛の返信は誰も読まないため、返信を受ける窓口は B-1 で別途必要です。

**C-4 は要件定義の FR-01-2「ソーシャルログイン(1 種)」に入っています**
(画面一覧の A-01 / A-02 にもボタンが明記されています)。実装は完了済みで、
残っているのは甲名義の Google Cloud プロジェクトで OAuth クライアントを
作っていただくことだけです。これが無いと FR-01-2 は動作確認できません。

なお未設定のあいだは、ログイン・会員登録画面に Google のボタンを出しません
(押しても Supabase の生エラー画面に飛ぶだけになるため)。
画面は壊れないので**検証公開のブロッカーにはなりませんが、
最終的な受入の前には必要**です。

## D. 決済(⚪ 後回し可)

| #   | もの                                     | 備考                                                       |
| --- | ---------------------------------------- | ---------------------------------------------------------- |
| D-1 | **Stripe アカウント**(甲名義)            | 本人確認・入金先口座の登録が必要。審査に数日かかることあり |
| D-2 | 本番 API キー / Webhook 署名シークレット | D-1 完了後に発行                                           |
| D-3 | **販売手数料率**の確定                   | 現在の設定は 7%。画面表示にのみ使用(精算処理は対象外)      |

Stripe が揃うまでは `CYCLEX_PAYMENTS_DISABLED=1` を入れて、
**購入導線だけを閉じた状態**で公開できます。閲覧・会員登録・出品・メッセージ・
評価・管理画面はすべて動きます。キーが揃った時点でフラグを外すだけで開通します。

> 売上金の出品者への送金・返金処理は別紙1 第3項により対象外です。
> 返金が必要な取引は管理画面に一覧され、甲が Stripe ダッシュボードで返金したあと
> 管理画面で消し込む運用になります。

## 依頼の優先順位

**まず「サイト名」を決めていただくのが最優先です。**
事業者名・メールアドレス・ドメインがすべてここに紐づいており、
決まらないうちは特商法表記を完成させられません。

そのうえで、この 5 つが揃えば決済以外は公開できます。

1. **サイト名の確定** → A-1 の残り 2 項目 / B-1 / B-2 がまとめて決まる
2. B-2 本番ドメイン(+ B-3 の DNS 権限)
3. C-1 Supabase / C-2 Vercel のアカウント
4. C-3 Resend の API キーと `EMAIL_FROM`
5. A-2 利用規約(依頼済み) / A-3 プライバシーポリシー

C-4(Google Cloud)は要件に含まれるため**受入の前には必要**ですが、
未設定でもボタンが出ないだけなので検証公開は先に進められます。
残り(C-5 / D / E)は後追いで差し込めます。

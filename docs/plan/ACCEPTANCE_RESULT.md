## 本番環境で再確認が必要な項目

ローカル検証では代替手段を用いたため、甲の環境で改めて確認してください。

| 項目                                                     | 理由・確認方法                                                                                                                                    |
| -------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| Stripe Checkout への実際のリダイレクトとテストカード決済 | ローカルには Stripe テストキーが無いため、Webhook を実署名で送出して決済確定以降を検証した。テストカード `4242 4242 4242 4242` での通し確認が必要 |
| Google ログインの実際の認証                              | Google OAuth クライアントの設定が必要。ボタンの表示と遷移処理の実装は確認済み                                                                     |
| Resend による実メール送信                                | ローカルではキー未設定のため送信をスキップしログのみ記録。送信ドメインの DNS 検証後に到達確認が必要                                               |

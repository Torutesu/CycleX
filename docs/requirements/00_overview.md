# 00. プロジェクト概要

## 1. 目的

自転車(主として中古自転車およびパーツ)を対象とする C2C マーケットプレイス「CycleX」について、**事業検証を目的とした最小限の機能(MVP)** を持つ Web アプリケーション 1 式を開発する。

MVP の検証仮説:

- 中古自転車・パーツの個人間売買に、汎用フリマアプリでは満たせない専門的なニーズ(フレームサイズ・コンポーネント・年式等のスペック検索)が存在するか
- 出品〜決済〜受渡〜評価の一連の取引フローが Web のみで成立するか

## 2. 前提条件

| 項目         | 内容                                                                                         |
| ------------ | -------------------------------------------------------------------------------------------- |
| 提供形態     | レスポンシブ対応 Web アプリケーション(**スマホファースト**で設計し、PC はレスポンシブで対応) |
| 対応ブラウザ | 開発時点の最新版 Chrome / Safari / Edge(iOS Safari・Android Chrome を含む)                   |
| 対応言語     | 日本語のみ                                                                                   |
| 対応通貨     | 日本円のみ                                                                                   |
| ユーザー種別 | 出品者・購入者・運営管理者の 3 種                                                            |
| 技術構成     | 開発者(乙)が選定([04_tech_stack.md](04_tech_stack.md) 参照)                                  |
| 想定稼働     | 契約期間全体で合計 160 時間程度                                                              |

### ユーザー種別の定義

| 種別               | 説明                                                                                                                                     |
| ------------------ | ---------------------------------------------------------------------------------------------------------------------------------------- |
| 出品者 (Seller)    | 会員登録済みユーザーのうち、商品を出品する者。専用の登録区分は設けず、**一般会員は誰でも出品・購入の両方が可能**(役割は取引ごとに決まる) |
| 購入者 (Buyer)     | 会員登録済みユーザーのうち、商品を購入する者                                                                                             |
| 運営管理者 (Admin) | 管理画面にアクセスできる運営スタッフ。一般会員とは別のロールとして管理し、管理画面は管理者ロールのみアクセス可能                         |

※ 未ログインの訪問者(ゲスト)は、商品の検索・一覧・詳細の閲覧のみ可能。お気に入り・メッセージ・購入・出品はログインが必要。

## 4. 対象外事項(別紙1 第3項)

以下は本業務に**含まれない**。実装・設計上の判断で境界が曖昧になりやすい点は補足を付す。

1. iOS / Android ネイティブアプリ、多言語対応、多通貨対応
2. 配送業者 API 連携、送り状発行、集荷手配、配送追跡
   - 補足: 取引フロー上の「発送連絡」はユーザーの手動操作+任意の追跡番号テキスト入力のみ。配送業者との連携は行わない
3. 本人確認(eKYC)、年齢確認、与信審査、防犯登録の照会・移転
4. エスクロー機能の自社実装、および資金の預り・移動を伴う機能
   - 補足: 決済は決済代行サービス(Stripe)の標準機能によるクレジットカード決済のみ。**売上金の出品者への送金・残高管理・出金申請等はシステム対象外**(検証期間中は運営が Stripe ダッシュボード等を用いてシステム外で対応する想定)
5. 法令適合性の確認、許認可の取得、利用規約・プライバシーポリシー等の作成
   - 補足: 規約・ポリシーの**掲載枠(静的ページ)** は用意するが、文面は甲が用意する
6. ロゴ、ブランドアイデンティティ、イラスト、写真素材の制作
7. SEO 施策、広告運用、アクセス解析基盤、SNS 連携
8. 負荷試験、脆弱性診断、セキュリティ監査、アクセシビリティ対応
9. 既存システム連携、大規模データ移行
10. リリース後の運用、監視、障害対応、保守、機能追加、カスタマーサポート、モデレーション運用
11. その他、別紙1 第2項に記載のない一切の機能

## 5. 用語定義

| 用語               | 定義                                                                                            |
| ------------------ | ----------------------------------------------------------------------------------------------- |
| 商品 (Listing)     | 出品者が登録した販売対象(車体またはパーツ)。下書き・公開・取下げ等の状態を持つ                  |
| 取引 (Transaction) | 購入申込から取引完了(またはキャンセル)までの一連のプロセス。1 商品につき有効な取引は同時に 1 件 |
| 受渡方法           | 商品の引き渡し手段。「配送」または「対面(手渡し)」                                              |
| 非表示化           | 管理者が商品・ユーザーを一般公開から除外する操作。データは削除しない                            |
| 退会               | ユーザー自身によるアカウント無効化。論理削除とし、取引履歴・評価は保持                          |
